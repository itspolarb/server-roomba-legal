Command guide

Everything happens inside Discord.

Server Roomba 1.13 public beta

Server Roomba uses slash commands instead of a hosted dashboard. Discord only shows options appropriate to each command, and sensitive setup responses are normally visible only to the person running them.

Getting started

Server managers should begin with:

  • /setup quickstart — apply safe recommendations for a community, gaming/RP, or creator/marketplace server.
  • /setup doctor — check channel access, role hierarchy, permissions, and required configuration.
  • /health — inspect runtime, database, scheduler, backups, failed jobs, and delivery diagnostics.
  • /module list — enable only the feature groups your community needs.

Member commands

  • /about — version, uptime, invite, support, privacy, and terms.
  • /feedback submit and /feedback bug — send an explicit structured report.
  • /privacy — policy, retention, data inventory, export, and voluntary-data deletion.
  • /tag, /suggest, /poll, /remind, and /birthday — community utilities.
  • /rank and /leaderboard — available when levels are enabled.

Staff commands

  • /mod, /casework, /incident, /temprole, and /voice — moderation operations.
  • /ticket — claim, prioritize, tag, note, reply to, close, reopen, and export tickets.
  • Support-role access does not automatically grant moderation authority.
  • Discord role hierarchy is always enforced, even when the bot command permits an action.

Bot-manager commands

  • /setup, /module, and /branding — server configuration and diagnostics.
  • /automod, /filter, and /raid — safety controls.
  • /welcome, /verify, and /rolemenu — onboarding and roles.
  • /ticket-type, /ticket-panel, and /ticket-reply — service-desk configuration.
  • /autoresponder, /sticky, /schedule, and /embed — automations.
  • /giveaway, /starboard, /counting, and level configuration — community tools.

Discover commands without this page

Run /help overview for command groups, /help getting-started for the recommended order, /help permissions for the access model, or /help command for one command group. Discord also provides descriptions for every subcommand and option.

Disabled modules keep their saved configuration but stop processing their commands and events.
