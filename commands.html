Link safety in 1.14

/links controls unwanted invites and suspicious links without forcing every server into the same policy.

  • Block outside Discord invites while allowing your own server or approved invites.
  • Maintain trusted-domain and blocked-domain lists.
  • Flag masked links, misleading display text, lookalike domains, URL shorteners, and risky file extensions.
  • Exempt trusted roles or channels and dry-run a policy before enforcement.
Privacy note: Server Roomba evaluates message text and attachment names. It does not open links, follow redirects, or download attachments.
