Command guide

You do not need to memorize dozens of commands. Start with /help; Discord will show each subcommand and its required options as you type.

Start a new server setup

/setup quickstart

Choose Community, Gaming/RP, Creator/marketplace, or Custom/manual. Presets adjust modules and basic protection settings; they do not create channels, roles, filters, policies, or panels.

/setup doctor

Checks permissions, role hierarchy, configured channels, tickets, verification, AutoMod, and other enabled features.

/health

Checks runtime status, storage integrity, scheduled jobs, backups, missing permissions, and failed deliveries.

/module list

Shows all 18 modules and whether each one is running.

Commands members can use

Information

/about /help /privacy

Bot details, command discovery, policies, data inventory, export, and voluntary-data deletion.

Community

/tag /suggest /poll /remind /birthday

Saved answers, suggestions, voting, reminders, and opt-in birthday settings.

Feedback

/feedback submit /feedback bug

Sends a structured report to Server Roomba support. It includes only the fields you submit plus the bot version, server ID, and selected module.

Levels, when enabled

/rank /leaderboard

Personal rank and server leaderboards are available only when a server enables the Levels module.

Commands for server staff

Moderation

/mod /casework /incident /temprole /voice

Handle moderation actions, case history, internal incidents, temporary roles, and voice-channel controls.

Tickets

/ticket

Claim, prioritize, tag, note, reply to, close, reopen, and export tickets. A support role does not automatically receive moderation power.

Commands for server managers

Server owners, members with Administrator or Manage Server, and delegated bot-manager roles can configure Server Roomba. Delegation does not grant kick, ban, timeout, or other moderation authority.

How modules behave

Disabling a module stops its commands and event processing but keeps its configuration. Re-enable it later and the setup is still there. Server Roomba currently includes 18 modules covering AutoMod, moderation, tickets, autoroles, role menus, raid protection, logging, welcomes, verification, birthdays, tags, suggestions, polls, automation, levels, giveaways, starboard, and counting.

Role hierarchy still wins. Discord will not let the bot manage a member or role equal to or above Server Roomba’s highest role.
