Straight answers

Before you invite it

Does it need Administrator?

No. The invite requests specific permissions for the available modules. You can remove permissions for features you disable.

Can each server configure it differently?

Yes. Modules, roles, channels, policies, tickets, automations, and branding are stored separately for every server.

Does it read every message?

Only enabled features that depend on message content process it—for example AutoMod, counting, autoresponders, ticket transcripts, and optional XP.

What happens if I remove it?

Your server data enters a 30-day grace period by default, then is deleted. Reinviting the bot during that window cancels the deletion.
