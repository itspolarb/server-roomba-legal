Setup steps

  1. Invite Server Roomba

    Open Discord invite

    Choose the server and approve the requested permissions.

  2. Place the bot role correctly

    In Server Settings → Roles, move Server Roomba above every role it must assign or manage. Discord never allows a bot to manage roles at or above its own.

  3. Run the quickstart

    Use /setup quickstart and choose Community, Gaming/RP, Creator/marketplace, or Custom/manual.

  4. Connect your channels and roles

    Set the audit channel, ticket category and support role, welcome channel, member role, and any module-specific destinations you plan to use.

  5. Review safety

    Configure AutoMod, verification, raid protection, and /links. Use dry runs where available before enforcing a new rule.

Why the permissions are requested

View and send

Required for commands, panels, logs, welcome messages, and ticket replies.

Manage messages

Used by AutoMod, link safety, purges, counting reactions, and scheduled cleanup.

Manage channels

Creates and maintains tickets, locks, and temporary channel settings.

Manage roles

Assigns verification, autorole, role-menu, quarantine, birthday, and reward roles.

Moderate, kick, and ban

Used only when an authorized command or configured safety rule calls for that action.

Read history and reactions

Supports context-aware tools, role menus, starboard, counting, and persistent panels.

Do not give Server Roomba Administrator. Give it only the listed permissions and restrict sensitive commands through Discord roles and channel permissions.

Good defaults before opening the doors

  • Keep the bot role below administrators and above only the roles it needs to manage.
  • Use a private audit-log channel that normal members cannot view.
  • Test ticket, verification, moderation, counting, and link policies with a non-staff account.
  • Review the Privacy Policy, Terms, and retention schedule.

Finish with two checks

Run /setup doctor for permissions and configuration, then /health for the database, scheduler, command registration, backups, failed jobs, and audit delivery.

If anything remains yellow or red, the response tells you what to fix.
