Installation guide

Invite, inspect, then configure.

No hosted dashboard or incoming server port is required.

1. Add Server Roomba

Use the official invite and choose the Discord server you manage.

Add Server Roomba

2. Choose a quickstart

Run /setup quickstart and choose Community, Gaming/RP, Creator/marketplace, or Custom/manual. A preset changes module recommendations and safe protection toggles only. It does not create channels, roles, filters, ticket panels, or policies.

Then configure your channels and roles and run /setup doctor. Use /health to inspect storage, scheduled work, backups, and delivery failures.

3. Understand requested permissions

PermissionWhy it is used
View Channels / Send MessagesCommands, panels, notices, logs, tickets, and scheduled messages.
Embed Links / Attach FilesReadable responses, configuration exports, and ticket transcripts.
Read Message HistoryReaction roles, starboard, counting, replies, and context-dependent tools.
Manage Messages / Add ReactionsAutoMod, cleanup, counting feedback, and reaction-role panels.
Manage ChannelsPrivate ticket channels, ticket archives, lock/unlock, and slowmode.
Manage Roles / NicknamesAutoroles, verification, role menus, quarantine, rewards, and optional nickname templates.
Moderate / Kick / Ban MembersStaff-requested moderation and configured automatic enforcement.
Mute / Move MembersVoice moderation commands.
Administrator is not required. Disable modules you do not use and remove permissions they no longer need.

4. Set the role hierarchy

Move the Server Roomba role above every role it must assign or remove and above members it must moderate. Discord prevents the bot from acting on equal or higher roles. Server Roomba checks these limits rather than attempting to bypass them.

5. Review data controls

Read the Privacy Policy, retention schedule, and Terms. Members can inspect and remove voluntary data with /privacy. Server owners have guarded server-data controls.
