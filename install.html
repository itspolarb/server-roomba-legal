Installation

Start clean. Add only what you need.

Server Roomba is configured with slash commands inside Discord. There is no dashboard account to create and no incoming server port to open.

1. Invite Server Roomba

You need permission to manage the Discord server. Choose your server on Discord’s authorization screen and approve the listed permissions.

Add Server Roomba

2. Choose a starting point

Run /setup quickstart:

Community

General moderation, onboarding, tickets, roles, and community utilities.

Gaming/RP

Starts with every module enabled for servers that want the complete feature set.

Creator/marketplace

Prioritizes moderation, verification, support, announcements, roles, and community feedback.

Custom/manual

Changes nothing. Use it when you want to choose each module yourself.

Quickstart does not create channels, roles, filters, rules, ticket panels, or verification policies. Those decisions stay with you.

3. Connect your channels and roles

Use /setup for logs, tickets, archive channels, staff roles, autoroles, protection, and delegated bot managers. Configure verification, welcome messages, ticket types, role menus, and other modules only if you plan to use them.

For verification, run /verify configure to choose roles and checks. Set captcha:True only if you want members to complete a private human check before receiving access, then publish either /verify policy or /verify panel.

4. Understand the permissions

PermissionUsed for
View Channels, Send MessagesCommands, panels, notices, logs, tickets, and scheduled posts.
Embed Links, Attach FilesReadable responses, configuration exports, ticket transcripts, and reviewed Meme vault storage.
Read Message HistoryRole menus, starboard, replies, Meme vault retrieval, and features that refer to existing messages.
Manage Messages, Add ReactionsAutoMod, cleanup, counting feedback, and reaction-role panels.
Manage ChannelsTicket channels and staff-requested channel controls.
Manage Roles, Manage NicknamesVerification, autoroles, role menus, quarantine, rewards, and nickname templates.
Moderate, Kick, Ban MembersStaff moderation commands and configured automatic enforcement.
Mute, Move MembersVoice moderation.
Administrator is not required. If you disable a module, you can also remove permissions used only by that module.

5. Put its role in the right place

Move the Server Roomba role above every role it needs to assign or remove and above members it needs to moderate. Discord blocks any bot from managing equal or higher roles.

6. Run the checks

/setup doctor

Finds missing permissions, inaccessible channels, incomplete module setup, and role-hierarchy problems.

/health

Confirms that Server Roomba is ready and explains any permission, setup, or delivery problems it finds.

/about

Confirms the running version and links to support, privacy, terms, and the invite.

Before opening the bot to members, review the Privacy Policy, retention schedule, and Terms of Service.
