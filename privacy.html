Privacy Policy

Effective July 25, 2026

Server Roomba is a Discord community-management bot operated by PolarBearr. This policy describes the data the hosted bot processes, why it is used, how long it is kept, and the controls available to members and server owners.

Data processed

Depending on the modules enabled by a Discord server, Server Roomba may process Discord server, channel, role, message, and user IDs; usernames and display names used to produce responses; server configuration; moderation cases; tickets and transcripts; verification acknowledgements; join and leave activity; voluntary birthday month and day; roles; suggestions, polls, votes, giveaway entries, XP, achievements, reminders, and automation records.

Message content is processed only where an enabled feature needs it, including AutoMod, counting, autoresponders, custom commands, ticket transcripts, audit logging, and message XP. Server Roomba does not request Discord presence data, collect payment-card data, sell personal data, or use data for advertising.

Why data is used

Data is used to provide server-selected moderation, safety, support, onboarding, role, community, automation, engagement, logging, and operational features; enforce reliability and abuse limits; diagnose failures; and comply with valid legal obligations.

Storage and sharing

The hosted deployment stores data in an operator-controlled SQLite database and private backups. Data is sent to Discord as needed to perform requested bot actions. Data may be disclosed to infrastructure providers, professional advisers, or authorities only when necessary to run the service, protect users, or meet legal obligations. Server Roomba does not sell data.

Retention and deletion

Operational history follows the published retention schedule. Active configuration, moderation cases, tickets, and verification policies are kept for server administration until deleted by the server owner or operator.

After the bot is removed from a server, that server’s database records are queued for deletion after the configured grace period, which is 30 days by default. Rejoining during the grace period cancels the queued deletion.

Member controls: use /privacy data, /privacy export, and /privacy delete. Server owners can use the guarded /setup delete-data command.

Voluntary member data can be deleted. Moderation cases, tickets, authored suggestions, Discord messages, and Discord roles are not removed by the member command because they are server-administration or Discord records.

Security and choices

The bot uses least-privilege Discord permissions, server-scoped database queries, protected environment files, structured logs, and integrity-checked backups. No system can guarantee absolute security. Members may avoid optional modules such as birthdays, XP, voting, and giveaways or ask server staff which features are enabled.

Children and international use

Server Roomba is intended for Discord users permitted to use Discord under Discord’s terms and applicable law. Server operators are responsible for suitable community access rules and local legal requirements.

Contact and changes

For privacy requests, questions, or abuse reports, email thepolarbearr@gmail.com. Material changes will update the effective date and may require server administrators to publish a new verification notice.
