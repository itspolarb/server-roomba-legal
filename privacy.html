Privacy Policy

What Server Roomba handles, why it needs it, and how long operational data is kept.

Data handledHow it is usedLink safetySharingYour control

Data Server Roomba may handle

Depending on enabled modules, the bot may store Discord server, channel, role, message, and user IDs; configuration; moderation cases; ticket records and transcripts; verification acceptance records; birthdays you voluntarily provide; scheduled jobs; suggestions, polls, giveaways, counting and starboard records; and operational error or audit-delivery details.

Server Roomba processes message content when a feature needs it—for example AutoMod, counting, autoresponders, tickets, custom feedback, memes, or link safety. It does not create a general-purpose archive of every message.

How the data is used

Data is used to provide the features chosen by each server, enforce its configuration, preserve necessary moderation or support history, prevent abuse, diagnose failures, and operate backups. Data is not sold and is not used for advertising.

Link and invite safety

When link safety is enabled, Server Roomba may parse message text, URLs, Discord invite codes, domain names, and attachment filenames to apply the server’s rules. It can compare those values with server-specific trusted and blocked lists and detect patterns such as masked links, lookalike domains, shorteners, or risky extensions.

Server Roomba does not open links, follow redirects, or download attachments. The checks are based on the information Discord delivers with the message.

Sharing and service providers

Server Roomba uses Discord to receive interactions and deliver results. Hosting and backup infrastructure may process operational data only as required to run the service. Data may be disclosed when legally required or necessary to protect the service and its users.

Optional meme sources receive normal requests from the bot’s server, not member Discord credentials.

Your choices and requests

Server managers control enabled modules and most stored server configuration. Server-specific data can be exported or deleted using authorized controls. Members can remove voluntarily provided birthday data through the applicable command.

For a privacy question or data request, email thepolarbearr@gmail.com. Include the Discord server ID and enough detail to verify the request. See the Data Retention Policy for normal storage periods.
