Help and feedback

Start with the bot’s own diagnostics.

Most setup problems are a missing permission, hidden channel, or role-order issue. Server Roomba can identify those directly.

Quick checksReport a problemWhat to includeContact

Quick checks

  1. Run /setup doctor in the affected server.
  2. Run /health and check permissions, command registration, failed jobs, and audit delivery.
  3. Confirm the Server Roomba role is above every role it needs to manage.
  4. Check that the bot can view and send messages in the affected channel.
  5. For link rules, inspect /links settings and try a dry run before changing enforcement.

Feedback and bug reports

Use /feedback submit for general feedback or /feedback bug for something broken. Reports include the bot version, server ID, and relevant module so the problem can be traced.

Message content is not included unless you explicitly put it in the report.

What makes a useful bug report

  • What you expected and what happened instead.
  • The command or feature you were using.
  • Whether the problem happens every time.
  • A screenshot of the response, with private information hidden.
  • The result of /health or /setup doctor when relevant.

Never send a Discord bot token, password, backup database, or private ticket transcript.

Contact

If the bot cannot submit feedback, email thepolarbearr@gmail.com. For privacy or deletion requests, include the Discord server ID and enough detail to verify your authority.
