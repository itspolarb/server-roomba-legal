Support & Abuse

Server Roomba public beta

Use this page for bot problems, privacy requests, security concerns, or reports of abusive Server Roomba use.

Email: thepolarbearr@gmail.com

Reporting a normal problem

Include the bot version, Discord server ID, affected command or module, approximate UTC time, and the ERR-... reference if Server Roomba displayed one. Remove message content and member information that are not necessary to understand the problem.

Abuse and privacy reports

Describe the affected Discord server, behavior, impact, and relevant evidence. For a data request, include your Discord user ID and the server ID, but do not send unrelated member data. You may also use the bot’s built-in /privacy commands.

Security reports

Do not publish exploitable security details. Explain the affected version, reproduction, expected impact, and any sanitized logs privately. Never send a Discord token, password, environment file, production database, or unredacted private transcript.

Response and resolution

Urgent security and privacy reports will be reviewed as promptly as practical. Only evidence necessary to investigate the report should be retained, and temporary evidence should be removed when it is no longer needed.
